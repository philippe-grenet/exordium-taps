# Treemacs

## Keys

Keybinding          | Description
--------------------|-------------------------------------------------------------------|
<kbd>F5</kbd>       | `treemacs` + adjusts frame width
<kbd>C-c e</kbd>    | `treemacs`
<kbd>C-c E</kbd>    | `treemacs-projectile`
<kbd>C-c t t</kbd>  | `treemacs-select-window`(select treemacs window if visible)
<kbd>C-c t s</kbd>  | `treemacs-switch-workspace`
